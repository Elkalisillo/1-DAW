El favicon de una página web

Un icono asociado al documento

Esta página tiene un favicon asociado. Si el navegador lo reconoce, aparecerá como un pequeño icono junto al título de la página en la pestaña. 

<link rel="icon" href="favicon.ico" type="image/x-icon">

rel → indica que el recurso es el icono de la página.
href → indica la ruta del archivo del icono.
type → indica el tipo de archivo.
    
El elemento link se encuentra dentro de head porque configura
un recurso asociado al documento, no contenido de la página.
