Ejemplo 1: tabla completa de datos

Una tabla HTML organiza información en filas y columnas.

- <table> contiene toda la tabla.
- <caption> identifica el contenido de la tabla.
- <thead> contiene las filas de cabecera.
- <tbody> contiene los datos principales.
- <tfoot> contiene información final o resumida.
- <tr> representa una fila.
- <th> representa una celda de cabecera.
- <td> representa una celda de datos.

En este ejemplo, <th> se utiliza para indicar qué representa
cada columna y <td> para los datos de cada equipo.

La estructura de la tabla puede entenderse de esta forma:

<table>
    <caption>Título de la tabla</caption>

    <thead>
        Cabeceras
    </thead>

    <tbody>
        Datos
    </tbody>

    <tfoot>
        Información final
    </tfoot>
</table>

Dentro de cada sección se utilizan filas <tr>.
Las cabeceras utilizan <th> y los datos utilizan <td>.

La organización mediante <thead>, <tbody> y <tfoot>
permite distinguir semánticamente las diferentes partes
de la tabla.
