Ejemplo 3: Listas HTML

HTML ofrece distintos tipos de listas según la información que
queremos representar.

- ol: presenta elementos en un orden numerado.
- ul: agrupa elementos sin establecer un orden numérico.
- dl: relaciona términos con sus definiciones.

Las listas ol y ul utilizan li para representar cada elemento.
Las listas dl utilizan dt para el término y dd para su descripción.

1. Lista ordenada

Pasos para preparar un proyecto web:

  1. Analizar los requisitos.
  2. Diseñar la estructura HTML.
  3. Crear las páginas.
  4. Comprobar el resultado.

2. Lista desordenada

Tecnologías utilizadas en el proyecto:

  • HTML
  • CSS
  • JavaScript
  • PHP

3. Lista ordenada con letras

Fases de una revisión:

  1. Revisar la estructura.
  2. Comprobar los contenidos.
  3. Validar el resultado.

4. Lista de definiciones

HTML
Lenguaje de marcado utilizado para estructurar el contenido de una página web.
CSS
Lenguaje utilizado para definir la presentación visual de una página web.
PHP
Lenguaje de programación que puede ejecutarse en el servidor para generar contenido web.
Patrones que debes reconocer en el código:

1. Lista ordenada:
   ol contiene varios li.

2. Lista desordenada:
   ul contiene varios li.

3. Lista ordenada con letras:
   ol utiliza type="A" para cambiar la numeración.

4. Lista de definiciones:
   dl contiene pares formados por dt (término) y dd (definición).

El tipo de lista depende de la relación entre los elementos:
si importa la secuencia, se utiliza ol; si no importa el orden,
se utiliza ul; si se relacionan términos con sus descripciones,
se utiliza dl.
