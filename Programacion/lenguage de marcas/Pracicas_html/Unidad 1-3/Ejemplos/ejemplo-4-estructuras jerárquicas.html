Ejemplo 4: Listas anidadas y datos combinados

Una lista puede contener otra lista dentro de uno de sus elementos li.
Así se representa una jerarquía: los elementos secundarios pertenecen
a un elemento principal.

También podemos incluir listas dentro de las celdas de una tabla.
La tabla organiza la información en filas y columnas, mientras que
la lista agrupa varios elementos relacionados dentro de una celda.

Observa la relación entre las etiquetas y el resultado:

- En la lista anidada, cada ul está dentro del li al que pertenece.
  Por eso, sus elementos aparecen como subtareas de una fase.

- En la tabla, tr representa cada fila y th o td identifica sus celdas.
  Dentro de una celda td puede incluirse una lista ul con varios li.

La tabla organiza los datos por filas y columnas. Las listas permiten
agrupar los elementos relacionados dentro de cada parte de esa tabla.
