Proyecto: página web de un restaurante

En esta página se organiza el desarrollo de la web de un restaurante: los pasos a seguir, los recursos necesarios, el reparto de tareas por áreas y algunos términos técnicos que aparecen en el proyecto.

1. Pasos del proyecto

Orden en el que se desarrollará la web:

  1. Reunirse con el cliente y anotar lo que necesita.
  2. Diseñar la estructura de las páginas.
  3. Escribir el código HTML de cada página.
  4. Añadir los estilos con CSS.
  5. Probar la web en distintos navegadores.
  6. Publicar la web en el servidor.

2. Recursos necesarios

Herramientas y materiales que se utilizarán:

  • Editor de código Visual Studio Code
  • Navegadores web (Chrome y Firefox)
  • Fotografías de los platos del restaurante
  • Carta con los precios actualizados
  • Servicio de alojamiento web

3. Tareas por áreas

Reparto del trabajo agrupado por categorías:

  • Diseño
    • Elegir los colores del restaurante
    • Preparar el logotipo
    • Seleccionar las fotografías
  • Programación
    • Página de inicio
    • Página de la carta
    • Página de contacto y reservas
  • Contenidos
    • Redactar la historia del restaurante
    • Escribir la descripción de los platos

4. Revisión antes de publicar

Fases de la revisión final, numeradas con letras:

  1. Comprobar que todos los enlaces funcionan.
  2. Revisar la ortografía de los textos.
  3. Validar el código HTML.
  4. Mostrar la web al cliente para su aprobación.

5. Glosario de términos

HTML
Lenguaje de marcado que se utiliza para estructurar el contenido de una página web.
CSS
Lenguaje que define el aspecto visual de una página: colores, tipos de letra, márgenes, etc.
Hosting
Servicio que guarda los archivos de la web en un servidor para que sea accesible desde Internet.
Dominio
Nombre con el que se accede a una web, por ejemplo www.restaurante.com.
